# My Capstone

Capstone project for the AI-assisted development track. The product idea is still open; this repo is the working tree for whatever we ship.

## Status

Scaffold only. There is no application code yet—just this README, an MIT license, and a Node.js-oriented gitignore.

## Stack

- **Runtime:** Node.js (planned)

Commits follow [Conventional Commits](https://www.conventionalcommits.org/) (`feat:`, `fix:`, `docs:`, `chore:`).

## Setup

Once the app exists, clone and install from the repo root:

```bash
git clone <repo-url>
cd capstone
npm install
```

Until a `package.json` is added, there is nothing to run.
